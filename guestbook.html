想让留言真的被看到？

有两种省事的做法，都不用自己写后端：

  1. giscus：用 GitHub Discussions 当留言区。在 giscus.app 授权仓库后，把生成的 data-repo-id / data-category-id 填进 _config.yml 的 giscus 段，这个页面就会自动换成真正的留言区。
  2. GitHub Issue：每张纸条做成一个 issue，简单粗暴但有效。

在此之前，这里就是个本地的便签墙 —— 也挺好，写完自己看看。
